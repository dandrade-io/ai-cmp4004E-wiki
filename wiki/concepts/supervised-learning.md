# Supervised Learning

**Intuition.** Learn a function from labelled examples so it predicts labels for inputs it has never seen. Syllabus topic 10 ([[slides-00-course-intro]]).

## Forms of learning (AIMA §19.1, p. 669–671)
- **Supervised:** input–output pairs → learn h ≈ f. **Classification** (finite outputs) vs **regression** (numeric outputs).
- **Unsupervised:** find patterns without feedback (e.g. clustering).
- **Reinforcement:** learn from rewards/punishments.
- Any agent component ([[agent-types]]) can be learned. **Induction** (specific → general) may be wrong, unlike deduction.

## Formal task (p. 671)
Given training set (x₁,y₁)…(x_N,y_N) generated by unknown y = f(x), find hypothesis h in hypothesis space H. h is **consistent** if h(xᵢ) = yᵢ. True quality = performance on a **test set** (generalization).

## Bias and variance (p. 672)
- **Bias:** systematic deviation caused by a restrictive hypothesis space → **underfitting**.
- **Variance:** sensitivity to the particular training set → **overfitting**.
- Bias–variance tradeoff; Ockham's razor prefers simple hypotheses. Probabilistic view: h* = argmax P(data|h)P(h) (prior favours smooth hypotheses).
- Tradeoff between *expressiveness* of H and *cost of finding* h in it.

## Model families in this course
[[naive-bayes]], [[linear-classifiers]] ([[perceptron]], logistic regression), [[support-vector-machine]], decision trees, nearest neighbours, ensembles, [[neural-networks-basics]]/[[deep-learning]]. Training usually = optimisation, e.g. [[gradient-descent]].

## Loss and goals (p. 687)
Learners minimise expected loss: 0/1 loss (error rate), L1 = |y−ŷ|, L2 = (y−ŷ)². Unequal costs matter (spam example: L(nospam→spam)=10). See [[overfitting-and-generalization]].
